# Історії «Пригод»

Тут лежить текст історій. Змінюйте його вільно: структуру й правила гри це не зачіпає.
Помилки (опечатка в полі, неіснуюче посилання, глава без виходу) покаже сервер при запуску,
із номером глави й вузла, а після виправлення достатньо перезапустити `npm run dev`.

Нова історія: новий файл `назва.json` за зразком `masquerade.json` і один рядок у
`core/games/adventures/stories.ts`. Історії проходяться по черзі, порядок рядків там і є порядком у грі.

У будь-якому тексті `{male}` і `{female}` замінюються іменами гравців.

## Що в історії

| Поле           | Що це                                                                         |
| -------------- | ----------------------------------------------------------------------------- |
| `id`           | Коротке ім'я латиницею, не змінюйте, коли історію вже грали (під ним прогрес) |
| `title`        | Назва на картці                                                               |
| `description`  | Опис на картці                                                                |
| `chapters`     | Глави. Кожна має `title` і список `nodes` (сцен)                              |
| `resurrection` | Завдання, коли герой не зміг сам повернутись. Скільки завгодно                |
| `ritual`       | Фінальний ритуал. Рівно 6 варіантів: його вибирає кубик d6                    |
| `epilogue`     | Фінальний текст після бажання                                                 |

Сцени йдуть по порядку: після кожної наступна в списку. Щоб піти кудись інакше, у сцені
є `id`, а розгалуження посилаються на нього. `"next": "end"` завершує главу.
Перша сцена кожної глави має бути `title`.

## Види сцен (`kind`)

- `title`: заголовок глави. `title`, `text`.
- `say`: оповідь або репліка. `text`, необов'язково `speaker` (хто говорить).
- `choice`: вибір. `chooser` (`male` чи `female`), `text`, `options`: список `{ "label", "next" }`, 2–4 варіанти.
- `check`: кидок d20. `roller`, `label` (підпис дії), `text`, `difficulty` (2–20, успіх при кидку не менше),
  `onSuccess` і `onFail`: `id` сцени для кожного результату. Якщо не вказано, іде наступна в списку.
- `dice`: кидок d6. `roller`, `text`, `outcomes`: список `{ "min", "max", "text", "next" }`. Діапазони мають покривати 1–6.
- `task`: завдання. `who` (`male`, `female` чи `both`), `title`, `text`, необов'язково `timer` у секундах.
- `effect`: втрата або здобуток. `who`, `text`, `hp` і/або `clothing` (наприклад, `-1`). Якщо життя доходить до нуля, герой падає.
- `reward`: предмет у скарбницю. `text` і `item`: `name`, `icon` (емодзі), `description`, необов'язково
  `effect`: `reroll` (перекинути кубик) або `swap` (передати завдання партнерові). Без `effect` предмет просто прикраса.

Спільні необов'язкові поля будь-якої сцени: `id` і `next`.

## Типовий вигляд розвилки

```json
{ "kind": "choice", "chooser": "male", "text": "…", "options": [
    { "label": "Порадувати", "next": "please" },
    { "label": "Прошмигнути", "next": "sneak" } ] },
{ "id": "please", "kind": "task", "who": "female", "title": "…", "text": "…", "next": "join" },
{ "id": "sneak", "kind": "check", "roller": "male", "label": "…", "text": "…", "difficulty": 11,
  "onSuccess": "sneak-ok", "onFail": "sneak-fail" },
{ "id": "sneak-ok", "kind": "task", "who": "male", "title": "…", "text": "…", "next": "join" },
{ "id": "sneak-fail", "kind": "effect", "who": "male", "clothing": -1, "text": "…" },
{ "kind": "task", "who": "male", "title": "…", "text": "…", "next": "join" },
{ "id": "join", "kind": "say", "text": "…" }
```

Гілка, що закінчується на `next`, перестрибує решту; гілка без `next` просто йде далі за списком.
